Security Notice: This demo uses an unsigned upload preset which is suitable for development/testing only. For production, implement a signed upload preset with server-side signature generation. Never expose your API Secret in frontend code.
Found in your Cloudinary dashboard under Account Details
Create an unsigned upload preset in Cloudinary → Settings → Upload
Images will be organized in this folder in your Cloudinary library
How to Set Up:
  1. Create a free account at cloudinary.com
  2. Go to Settings → Upload → Add upload preset
  3. Set Signing Mode to Unsigned
  4. Copy your Cloud Name and Preset Name above
  5. Update the values in assets/js/cloudinary.js
